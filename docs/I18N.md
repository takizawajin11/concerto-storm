# 翻訳の進め方（英語版・フランス語版）

日本語版 index.html から、プログラムを正しく読み解いて「訳す単位」を取り出し、訳を当てはめて en/index.html・fr/index.html を作る。

1. `python3 tools/build.py`（日本語版を作る）
2. `node tools/i18n/i18n.mjs scan`（i18n/units.json を作る。初回は `cd tools/i18n && npm i`）
3. `python3 tools/i18n/chunks.py`（/tmp/tr/c_NN.txt に小分け。1行は「番号|印|日本語」。印 T=差し込みつき、R=正規表現、I=プログラム上の名前、C:=照合に使われる）
4. 小分けごとに訳を書く：`i18n/src/en_NN.tsv`（フランス語は `fr_NN.tsv`）。1行は「番号<TAB>訳」。改行は `\n`
   - ⟦0⟧⟦1⟧ は差し込み。訳の中で順番を入れ替えてよいが、全部使う。⟦0|mon⟧ と書くと月の名前になる（i18n/<lang>.helpers.js）
   - R（正規表現）は、訳した文に合う正規表現を書く
   - C・I の印がある語は、プログラムが名前や照合に使う。同じ訳を別の語に使わない（merge.py が警告する）
5. `python3 tools/i18n/merge.py en` → `node tools/i18n/i18n.mjs apply en` → `CS_URL=http://localhost:8766/en/index.html python3 tests/smoke.py s1781`
6. 文言を足したり変えたりすると番号が変わる。そのときは 2・3 をやり直し、番号ではなく日本語をもとに訳を引き継ぐこと（en.tr.json は日本語がキー）

セーブデータは言語ごとに別（concertoStormEN_… ）。人名は tools/i18n/chunks.py が欧文名から自動で埋める。
