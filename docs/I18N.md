# 翻訳の進め方（英語版・フランス語版）

日本語版 index.html から、プログラムを正しく読み解いて「訳す単位」を取り出し、訳を当てはめて en/index.html・fr/index.html を作る。

## ふだん（文言を変えていないとき）

`bash tools/i18n/all.sh` … 日本語版・英語版・フランス語版をまとめて作り直す（初回は自動で `npm i`）。

## 文言を足した・変えたとき

1. `bash tools/i18n/all.sh` … 「未訳の箇所 N」と出る（未訳は日本語のまま表示される）
2. `python3 tools/i18n/chunks.py en` … まだ訳のないものだけを /tmp/tr/c_NN.txt に書き出す（1行は「番号|印|日本語」。印 T=差し込みつき、R=正規表現、I=プログラム上の名前、C:=照合に使われる）
3. 訳を `i18n/src/en_NN.tsv` に書く（フランス語は `chunks.py fr` → `fr_NN.tsv`）。1行は「番号<TAB>訳」。改行は `\n`
   - ⟦0⟧⟦1⟧ は差し込み。訳の中で順番を入れ替えてよいが、全部使う。⟦0|mon⟧ と書くと月の名前になる（i18n/<lang>.helpers.js）
   - R（正規表現）は、訳した文に合う正規表現を書く（訳文の言い回しとそろえること）
   - C・I の印がある語は、プログラムが名前や照合に使う。同じ訳を別の語に使わない（merge.py が警告する）
4. `python3 tools/i18n/merge.py en` … `i18n/en.tr.json`（日本語がキー）に取り込み、tsv は `i18n/done/` へ移る
5. `bash tools/i18n/all.sh` → `CS_URL=http://localhost:8766/en/index.html python3 tests/smoke.py s1781`

## 覚え書き

- 訳の本体は `i18n/<lang>.tr.json`。番号（units.json の id）は文言を足すと変わるので、tsv は取り込んだら使い回さない
- 人名は `i18n/names.json`（欧文名）から chunks.py / merge.py が自動で埋める
- 日本語の文字を含まない全角記号だけの断片（「、」や括弧）と、全角括弧に頼る正規表現は、i18n.mjs の PUN・REPUN の表で言語ごとに読み替える
- 訳文どうしで言い回しをそろえる必要がある組（正規表現と照合）：年表に載せる日誌の言い回し（2261 番あたり）、「見せ場《」、独奏・ヴィオラ・オーボエの席名、鑑定と偽物、「9席中◯席」「全9席」「9席」、現在$、街角へ出る、タブ名（派遣公演・挑戦状・時の扉）
- セーブデータは言語ごとに別（concertoStormEN_… / concertoStormFR_…）。音源は ../snd/ を読む
- 言語の切り替えリンクは 215_lang.js（タイトルの下）
- 言語ごとの見た目の調整は `i18n/<lang>.css`
