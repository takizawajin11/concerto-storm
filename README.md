# 協奏の嵐 ― Concerto Storm

クラシック音楽史を舞台にした歴史シミュレーションゲーム。
1723年のバロックから1905年の新世紀まで、5つの時代のどれかで名音楽家のひとりとなり、
仲間を口説き、演奏で競い、楽団を育てて巡演し、ヨーロッパの楽壇の頂点をめざします。

## 遊び方

ブラウザで `index.html` を開くだけで遊べます（インストール不要・スマートフォン対応）。

- **旅と説得**：都市を巡り、音楽家を口説いて楽団に迎える
- **演奏対決・演奏会**：ライバルとの対決、演目と布陣を決めての演奏会
- **稽古場と巡演**：楽団員を育て、愛用の楽器を持たせ、会場を一夜ずつ巡って都市を手に入れる
- **時の扉**：別の時代の音楽家を客演に招く

## 記録の保存と共有

- 進行と「楽団史の殿堂」は、遊んでいる端末のブラウザに自動で保存されます
- タイトル画面の「データの控え」から、セーブをファイルに書き出して別の端末へ移せます
- 楽団史は「この楽団史を見せる」から、リンクと画像カードで共有できます。リンクには記録そのものが入っているので、受け取った人はゲームのデータがなくても読めます
